# Carform Studio prototype

A responsive, buildless car customization prototype. Open `dist/index.html` in a modern browser or serve the `dist` folder with any static web server.

## Included interactions

- Vehicle details for build name, year, make, model, and trim
- Exterior and cabin photo uploads with in-session preview selection
- Separate exterior and interior views with demo imagery
- Wrap color and finish, glass VLT controls, wheel design and size, ride-height preference, and interior choices
- Three-step vehicle, customization, and review flow
- Local device saves, JSON brief download, and share/copy build summary
- Responsive layouts for phone, tablet, and desktop

## Prototype limits

- Build saves use browser local storage on the current device. Uploaded photos remain in the current session.
- Demo photo effects are illustrative. The prototype does not segment or render modifications accurately onto arbitrary uploaded photos.
- It does not generate installation prices, verify tint laws, confirm fitment, connect to a shop, or store builds on a server.
